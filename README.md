# PokerSim — learn statistics by playing poker

A No-Limit Texas Hold'em simulator that shows the math behind every decision:
equity, pot odds, expected value (EV), outs, variance, confidence intervals,
hypothesis tests, Bayes' theorem and more. Every number has a **"Show the math"**
panel with the formula and your actual values plugged in.

No dependencies, no build step. Plain JavaScript (ES modules) + HTML + CSS.

## Run it

```bash
npm start
```

Then open http://localhost:8080. (Any static server works, e.g. `python3 -m http.server`.
It must be served over HTTP: browsers block ES modules from `file://`.)

## What's inside

| Tab | What you do | Statistics you learn |
|---|---|---|
| **Play** | Play 2–6 handed NLHE against bots with distinct styles | Equity (Monte Carlo ± 95% CI), pot odds, EV(call), EV(bet) with fold equity, outs, final-hand distribution, Bayesian range estimates |
| ↳ This hand | Decision-by-decision review after each hand | Your estimated equity vs equity against the opponents' *actual* cards (information vs. outcome) |
| ↳ Session stats | Win rate, SD, CI, z-test, all-in EV ("luck") line, result histogram | bb/100, standard error, confidence intervals, p-values, skewness, √n cone |
| ↳ Player stats | VPIP / PFR / AF / WTSD / W$SD / fold-to-bet for everyone | Proportions with Wilson intervals; why small samples mislead |
| ↳ Fast-forward | Let a bot play your seat for 100–5,000 hands | Law of large numbers in your own session |
| **Equity Lab** | Hands, ranges or random hands vs each other, any board | Exact enumeration vs Monte Carlo, convergence chart with CI band, √n law |
| **Odds & EV** | Pot-odds calculator, bluff calculator, call/fold quiz, outs trainer | EV as a linear function, break-even fold equity, implied odds, rule of 2 and 4 vs exact |
| **Probability** | Theory vs simulation for 10 events; 7-card frequencies | Combinatorics, complement rule, conditional probability, z-scores, chi-square test |
| **Ranges & Bayes** | 13×13 range grid, blockers, equity vs range, Bayesian updating | Combos, card removal, prior × likelihood → posterior |
| **Variance** | Simulate thousands of players with the same skill | Normal approximation, CLT (bootstrap from real hands), downswings, risk of ruin |
| **Learn** | Guided path + 30 concept explanations | Everything above, with worked poker examples |

Bot styles: Tight-Aggressive, Loose-Aggressive, Calling Station, Nit, Maniac, Pot-Odds bot.
Each bot's log line shows its reasoning (e.g. *"equity ≈ 34% vs 1 random hand, needs 25% to call: call"*).
Use a **seed** in Table settings to replay identical cards.

## Proof of correctness

```bash
npm test          # 27 unit tests (~20 s)
npm run verify    # enumerates all 133,784,560 seven-card hands (~20 s)
npm run test:ui   # headless-browser smoke test of every tab (needs Playwright)
```

What the tests check:

- **Hand evaluator**: all 2,598,960 five-card hands and all 133,784,560 seven-card hands
  match the textbook category counts exactly.
- **Equity**: exact enumeration reproduces published results — A♠A♥ vs K♠K♥ wins 82.36%,
  vs K♦K♣ 81.06% (all 1,712,304 boards). Monte Carlo lands within its confidence interval of the exact answer.
- **Fair dealing**: chi-square p-values across 30 seeds are uniformly distributed (unbiased shuffle + RNG).
- **Game engine**: blinds and action order (heads-up and multiway), min-raise rules, short all-ins
  that don't reopen betting, uncalled-bet refunds, side pots, and 5,000 bot hands with exact chip conservation.
- **Statistics**: normal CDF/inverse, Wilson interval, chi-square p-values, Beta distribution vs reference values.

## Simplifications (stated so you can reason about them)

- "Immediate EV" of a call assumes no further betting; implied odds are shown separately.
- Raise EV assumes at most one caller and uses equity vs estimated ranges when called.
- Opponent ranges in the HUD are "top X%" of hands, X = Bayesian estimate of their VPIP/PFR.
- Bots are heuristic (equity vs random hands + style parameters), not game-theory optimal.
